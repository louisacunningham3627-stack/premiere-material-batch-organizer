# 设计说明

## 1. 产品目标

为 Premiere 项目把新导入的项目专用素材按交接批次归集到磁盘目录，同时保留受保护共享素材原位引用。

## 2. 主要用户

高频剪辑和后期交接人员，在 Premiere 的窄工具面板中快速确认当前批次、启动归集并交接给下一位剪辑者。

## 3. 设计原则

1. 错搬比晚搬严重：任何移动前都要把保护命中、冲突和未保存工程讲清楚。
2. 批次就是交接对象：只展示用户真正需要交接的批次，不制造工程副本或类型分箱。
3. 显示事实，不堆设计：磁盘路径、文件数量、体积和状态优先于装饰。
4. 高频动作要短：打开本批素材、标记已交接和归集开关在首屏完成。

## 4. 界面验收标准

用户能在 10 秒内确认当前批次与保护命中情况，并启动归集或打开交接目录。一次交接完成后，能明确看到下一批次已准备好。

## 5. 不在本版范围内

- 不管理、复制、移动、改名或打包任何 `.prproj`。
- 不在 Premiere 项目面板内按视频、音频或来源创建分箱。
- 不按来源、接手人或媒体类型生成物理子目录。
- 不提供无预览的整项目历史路径重排。

## 6. 已确认约束

- **2026-09-02**：当前批次目录本身就是交接对象，不生成额外交接包。原因：日常交接按新增素材批次进行，减少再次查找。
- **2026-09-02**：不保留 `.prproj` 副本，也不把工程文件放入素材批次。原因：工程文件由用户自行管理，避免与素材归集混淆。
- **2026-09-02**：原始素材与临时下载素材都自动归集；保护目录只读保留。原因：用户希望清理磁盘，而不是复制一份后继续手动删除。
- **2026-09-02**：中断恢复只核对素材项身份、文件和现有链接，再补记账目；不主动改链或删除任何文件。原因：恢复时上下文可能不完整，宁可留下一个待清理副本，也不能改错链接或删错素材。
