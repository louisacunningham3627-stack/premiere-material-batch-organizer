# 赫朝素材自动整理 macOS 版

> 0.2.0 为候选版本。macOS 废纸篓助手尚未实现，也未完成 Premiere 真机验收；即使目标已建立并补链，原文件仍保留并提示待回收。不要将本包作为已支持自动搬完的正式版本。包内不附带 Windows 可执行助手。

## 安装

1. 保存工程并完全退出 Premiere Pro。
2. 双击打开本文件所在文件夹，在终端执行：

```bash
cd "本文件夹路径"
chmod +x 安装-macOS.sh
bash 安装-macOS.sh
```

安装脚本默认把本文件夹的 `plugin/` 放到 `~/Library/Application Support/Adobe/UXP/Plugins/External/`。安装完成后启动 Premiere，在“窗口 > UXP 插件”中打开“赫朝素材自动整理”。

## 卸载与恢复

退出 Premiere 后执行 `bash 卸载-macOS.sh`。脚本只移动插件目录到 `PluginBackups`，不会直接删除。

卸载输出的备份路径可用以下命令恢复：

```bash
chmod +x 恢复-macOS.sh
bash 恢复-macOS.sh --backup-path "备份路径"
```

若安装校验失败，旧版会自动回到原安装位置；失败的新版本会留在 `PluginBackups` 供检查。

## 使用与限制

插件只整理当前工程引用、但位于工程文件夹外的单文件素材，不会移动、改名或打包 `.prproj`。工程文件夹内和“不搬动文件夹”里的素材保持原位。同目录多个 `.prproj` 按工程目录共享设置、日期文件夹和不搬动名单；添加、更换或移除名单后先暂停并重新确认。升级旧版时只保留已选择的本机文件夹路径，不继承旧版确认或开启状态。`/Users/...` 和 `/Volumes/...` 路径保留大小写。源文件和目标目录的 `lstat.dev` 相同才优先尝试硬链接，否则排他复制。源文件必须提供有效的 `dev + ino`，缺失时停止并提示。没有 macOS 系统废纸篓接口时，原文件保留，不会降级永久删除。

macOS Premiere 的真实素材搬运、外置卷权限、重链接和工程保存仍需在临时工程中人工验收，静态包校验不能替代这一步。
