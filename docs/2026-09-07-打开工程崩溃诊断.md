# 2026-09-07 打开工程崩溃诊断

## 结论

已确认 Premiere 26.0.1.3 在 Adobe UXP 原生模块 dynamic-torqnative.dll 8.1.0.0 中发生访问异常；尚未取得符号化调用栈或完成停用插件对照，不能声称根因已经完全确认。

当前高优先级嫌疑为素材整理插件 0.2.7 的精确文件身份适配：`src/transaction.js` 中 `lstatForIdentity()` 用 `Object.create(after)` 包装原生 Stat，再由扫描代码调用继承的 `isFile()`。该调用把接收对象由原生 Stat 改成普通 JS 对象；原生绑定若依赖内部对象身份，可能拒绝或崩溃。Node 中用 WeakSet 模拟原生接收对象约束可复现拒绝，但不等于复现真实 UXP 访问异常。
